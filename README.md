# Discord Bot

A comprehensive Discord bot for Minecraft, gaming, streaming, and digital content communities.

## Features

- Moderation
- Security
- Tickets
- Economy
- Levels
- Minecraft Integration
- Streaming Notifications
- Giveaways
- Utilities
- Administration
- AI

## Requirements

- Python 3.9 or higher
- discord.py
- python-dotenv
- sqlite3

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file based on `.env.example`
4. Run the bot: `python bot.py`

## Usage

### Commands

- `!role <action> <role> <member>`: Manage roles
- `!ticket <category>`: Create a ticket
- `!stats`: Display server statistics
- `!balance <member>`: Display balance
- `!pay <member> <amount>`: Pay a member
- `!language <language>`: Change language
- `!announce <message>`: Make an announcement
- `!permission <action> <command> <role>`: Manage permissions
- `!staff <action> <member>`: Manage staff
- `!stream <platform> <username>`: Set up streaming notifications
- `!event <action> <event_name> <details>`: Manage events
- `!giveaway <action> <details>`: Manage giveaways
- `!notify <platform> <username>`: Set up notifications
- `!config <category> <setting> <value>`: Configure the bot
- `!minecraft`: Display Minecraft server status
- `!warn <member> <reason>`: Warn a member
- `!kick <member> <reason>`: Kick a member
- `!ban <member> <reason>`: Ban a member
- `!poll <question> <options>`: Create a poll
- `!rank <member>`: Display rank
- `!play <query>`: Play music
- `!ai <question>`: Get an AI response
